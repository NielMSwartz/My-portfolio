# Documents

The real, original PDF files are installed here:

| File name                    | Document               |
| ---------------------------- | ---------------------- |
| `cv.pdf`                     | Curriculum Vitae       |
| `samtrac-certificate.pdf`    | SAMTRAC Certificate    |

Both are enabled in `js/config.js` with `available: true`.

To replace a document, overwrite the matching file or update its `path` in
`js/config.js`. To hide one temporarily, set `available: false`; the website
will show an honest "Not added yet" state and disable the download button.

Do not add placeholder or fabricated qualification documents.
